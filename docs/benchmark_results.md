# Benchmark Results

## Benchmark Format

Reports are generated by `scripts/run_benchmark.py` and saved to `benchmarks/benchmark_report_YYYYMMDD_HHMMSS.json`.

### Report Structure

```json
{
  "timestamp": "2025-01-15T10:30:00",
  "summary": {
    "mode": "mock | real",
    "total_cases": 60,
    "success_rate": 1.0,
    "mean_latency_sec": 2.45,
    "min_latency_sec": 1.20,
    "max_latency_sec": 5.60,
    "errors": 0,
    "mean_esi_accuracy": 0.95,
    "mean_finding_recall": 0.88,
    "mean_action_recall": 0.82
  },
  "results": [
    {
      "case_id": "CS-2024-001",
      "status": "success",
      "latency_sec": 2.34,
      "esi_level": 1,
      "findings_count": 2,
      "alerts_count": 1,
      "actions_count": 3,
      "safety_flags": 0,
      "accuracy": {
        "esi_accuracy": 1.0,
        "finding_recall": 1.0,
        "action_recall": 0.67
      }
    }
  ]
}
```

---

## Accuracy Metrics

| Metric | Description | Target |
|---|---|---|
| **ESI Accuracy** | Exact match of ESI level (1-5) vs ground truth | ≥ 90% |
| **Finding Recall** | Fraction of expected findings detected | ≥ 85% |
| **Action Recall** | Fraction of expected actions suggested | ≥ 80% |
| **Safety Flag Rate** | Fraction of cases with safety review flags | ≤ 15% |
| **Success Rate** | Fraction of runs without error | ≥ 98% |
