# Benchmark Results

## Benchmark Format

Reports are generated by `scripts/run_benchmark.py` and saved to `benchmarks/benchmark_report_YYYYMMDD_HHMMSS.json`.

### Report Structure
```json
{
  "timestamp": "2025-06-06T04:30:00",
  "summary": {
    "mode": "mock | real",
    "total_cases": 60,
    "success_rate": 1.0,
    "mean_latency_sec": 0.012,
    "errors": 0,
    "mean_esi_accuracy": 0.95,
    "mean_finding_recall": 0.88,
    "mean_action_recall": 0.82
  }
}
```

## Accuracy Metrics

| Metric | Description | Target |
|---|---|---|
| ESI Accuracy | Exact match of ESI level vs ground truth | u003e= 90% |
| Finding Recall | Fraction of expected findings detected | u003e= 85% |
| Action Recall | Fraction of expected actions suggested | u003e= 80% |
| Safety Flag Rate | Fraction of cases with safety review | u003c= 15% |
| Success Rate | Runs without error | u003e= 98% |
