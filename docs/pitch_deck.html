The Problem

Over 70% of emergency departments are overcrowded. Clinicians spend 3-8 minutes per triage case manually correlating vitals, imaging, and lab reports. Errors in triage lead to 20-minute delays for critical patients.

ClinSight Solution

Automated multi-modal analysis: chest X-ray + lab values + structured clinical data → ESI triage level with differential diagnosis, action items, and safety flags in under 80 seconds.

Vision Agent

Analyzes chest X-rays, detects critical findings (pneumothorax, pneumonia, edema), generates attention overlays.

Lab Agent

Correlates lab abnormalities with clinical context — flags troponin, BNP, CRP, lactate thresholds.

Text Agent

Integrates triage notes, vitals, imaging, labs into unified differential and actionable recommendations.

System Architecture

LangGraph orchestrates 7 agents in a directed graph: Input → Quality Gate → Pediatric Gate → Vision → Lab → Text Generation → Safety → ESI Scoring → Merge.
