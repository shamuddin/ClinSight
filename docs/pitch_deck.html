ClinSight

Multi-agent clinical decision support with vision-language models for chest X-ray analysis

5 Parent Agents 7 Subagents 12 Reasoning Nodes ESI 1-5 Scoring Safety Layer AMD MI300X Native

Coordinator Agent

Routes cases, manages workflow state, and orchestrates parallel agent execution.

Radiologist Agent

Vision-language analysis of chest X-rays with structured finding extraction.

Lab Analyst Agent

Cross-references lab values against radiological findings for multimodal reasoning.

Safety Layer

3 parallel checks (contradictions, hallucinations, bias) with merge node arbitration.

Deterministic ESI

Never LLM-based. Rule-based Emergency Severity Index scoring for clinical reliability.

Contingency Fallback

AMD Advantage

Hardware differentiation that unlocks dual-model deployment

AMD MI300X

  • 192 GB HBM3 unified memory
  • Fits TWO vision-language models simultaneously (~85 GB total)
  • ROCm 7.2 + vLLM native stack
  • $1.99/hr cloud instance cost

NVIDIA H100 80 GB

  • 80 GB HBM3 — cannot fit both models
  • Requires model sharding or sequential loading
  • ~$8/hr for comparable cloud instance
  • 4x cost, 0.4x usable memory per device

Architecture

Agent graph with deterministic safety and deterministic scoring

Agent Graph

Coordinator → Radiologist Agent / Lab Analyst Agent → Safety Layer → Documenter

Safety Layer

3 Parallel Checks (Contradiction, Hallucination, Bias Audit) + Merge Node arbitration

Deterministic ESI Scorer

Rule-based scoring engine. Never delegated to an LLM. Auditable and reproducible.

Contingency Fallback

< 0.2s failover when GPU is offline. Static rule fallback for 100% uptime.

Physician Veto

Agree / Override / Dismiss — every recommendation requires human-in-the-loop sign-off.
