Architecture

LangGraph compiled pipeline: Coordinator → [pass] → Analysis (Radiologist + Lab) → Safety (3 parallel) → Documenter → END

  • Coordinator: Image Quality Gate + Pediatric Safety Gate
  • Radiologist: Image Prep → Pathology Analyzer (VLM call)
  • Lab Analyst: Critical Value Detector → Pattern Correlator
  • Safety: Contradiction Checker ↔ Hallucination Guard ↔ Bias Auditor → Merge Node
  • Documenter: ESI Scorer (deterministic) + Differential Builder + LLM Report

  • Clinical Sign-Off: Case-by-case advisory, documented failure modes
  • Physician Veto: Every output requires clinician review
